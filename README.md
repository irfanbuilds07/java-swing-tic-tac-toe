🎮 Java Swing Tic-Tac-Toe
  A modern Tic-Tac-Toe game built with Java Swing, featuring a clean dark theme and interactive gameplay.
  
✨ Features
🎨 Modern dark-themed GUI
❌⭕ Two-player gameplay
🏆 Automatic winner detection
🟩 Winning combination highlighting
🤝 Draw detection
🔄 Restart functionality

🛠️ Technologies Used

    Java
    Java Swing
    AWT Color and GUI utilities

🚀 How to Run
Prerequisites

Java JDK installed
VS Code or another Java IDE

Steps

1.Clone this repository:
    git clone https://github.com/irfanbuilds07/java-swing-tic-tac-toe.git

2.Open the project folder in VS Code.

3.Compile the Java file:
      javac TicTacToe.java

4.Run the game:
    java TicTacToe
